A repository for storytelling and script-generation skills for Claude Code and related creative workflows.

## Included skill

- [SKILL.md](./SKILL.md) — video script generation skill for YouTube, TikTok, Instagram Reels, tutorials, and talking-head content.

- [storytelling-frameworks](https://github.com/advisorita/storytelling-frameworks) — a public repository with six proven short-form storytelling frameworks and templates.

## Notes

This repo stores reusable prompt/skill assets for structuring compelling narratives, hooks, visual cues, shot lists, and production-ready scripts.
